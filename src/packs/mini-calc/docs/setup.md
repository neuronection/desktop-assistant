# Setup

The calculator ships **bundled and enabled** with Desktop Assistant —
there is nothing to install.

- **Enable/disable**: Settings → Apps → Mini-apps → the Calculator
  card. Disabling removes the palette entry (the pack's command
  contribution stops registering).
- **Remove**: the card's remove action. Removing a bundled pack is
  sticky — it never comes back on the next boot until you explicitly
  restore it from the Mini-apps tab.
- **No configuration**: the pack declares no config keys; behavior is
  fully owned by the host mode chrome (placeholder, hints, exit
  ladder).
